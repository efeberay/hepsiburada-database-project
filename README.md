# Hepsiburada Database Project

## Türkçe Açıklama

Bu proje, Hepsiburada benzeri bir e-ticaret sisteminin SQL Server üzerinde hazırlanmış veritabanı tasarımını içermektedir.

Projede müşteriler, satıcılar, ürünler, kategoriler, sepetler, siparişler, ödeme ve kargo bilgileri için ayrı tablolar oluşturulmuştur. Tablolar arasında birincil anahtar ve yabancı anahtar ilişkileri kurulmuştur. Böylece veritabanı üzerinde ilişkisel yapı sağlanmıştır.

Bu proje okul veritabanı dersi kapsamında hazırlanmıştır.

## Kullanılan Teknolojiler

- Microsoft SQL Server
- SQL Server Management Studio
- T-SQL
